# Python DSA Practice

Random DSA/problem-solving scripts. Learning Python, trying stuff out.

## What's in here

- **fizz-buzz.py** — Classic FizzBuzz (1-100)
- **recursion_fibbonacci.py** — Fibonacci with recursion
- **recursive_power_of_2.py** — Power of 2 calculation
- **count-digits-that-divide-number.py** — Check which digits divide the number
- **palindrome_check.py** — String palindrome validation
- **hcf.py** — Highest common factor
- **power.py** — Power function
- **odd-number-count-in-interval-range.py** — Count odds in range
- **how-many-numbers-smaller-than-current-number.py** — Array comparison
- **kids-with-candies.py** — LeetCode-style problem
- **subtract-product-sum-of-integer.py** — Math operations on digits
- **print_recursion.py** — Basic recursion demo
- **main.py** — Entry point (minimal)

## Running

```bash
python <script>.py
```

Or use `uv` for dependency management:

```bash
uv run <script>.py
```
